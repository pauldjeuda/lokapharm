Politique de confidentialité

Dernière mise à jour : octobre 2026

Responsable : LokaPharm (cm.Lokapharm.app) — contact@Lokapharm.cm

1. Données collectées

  • Localisation précise (si vous l’autorisez) : pour afficher les pharmacies proches et calculer des itinéraires.
  • Favoris : stockés uniquement sur votre appareil.
  • Cache technique : listes de pharmacies pour améliorer les performances hors-ligne.

Nous ne créons pas de compte obligatoire, ne collectons pas de documents de santé dans la version actuelle, et n’utilisons pas de publicité ni d’identifiant publicitaire.

2. Finalités

Fournir les fonctionnalités de l’application : carte, liste, recherche, itinéraires, favoris et navigation.

3. Partage avec des tiers

Lorsque vous utilisez la carte ou les itinéraires, vos coordonnées peuvent être transmises aux services suivants, uniquement pour ces finalités :

  • API LokaPharm (agrégation pharmacies)
  • OpenStreetMap / Overpass (recherche d’établissements)
  • Nominatim (géocodage)
  • OSRM (calcul d’itinéraires)
  • Fournisseurs de tuiles cartographiques

4. Conservation

Les favoris et le cache restent sur votre appareil. Vous pouvez les supprimer en effaçant les données de l’application ou en la désinstallant.

5. Sécurité

Les communications réseau utilisent HTTPS. Aucun mot de passe n’est collecté dans la version actuelle.

6. Vos droits

Vous pouvez refuser la localisation à tout moment dans les paramètres de l’appareil. Contact : contact@Lokapharm.cm.

7. Avertissement santé

LokaPharm est un outil d’information et d’orientation. Il ne remplace pas un avis médical, une consultation, ni une urgence sanitaire. Ce n’est pas un dispositif médical.
