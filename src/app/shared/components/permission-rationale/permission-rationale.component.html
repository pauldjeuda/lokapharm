Pourquoi nous avons besoin de votre position

LokaPharm utilise votre position uniquement pour afficher les pharmacies à proximité, calculer les distances et les itinéraires. Vos coordonnées peuvent être transmises à notre API et aux services cartographiques (OpenStreetMap, OSRM) pour ces fonctionnalités. Elles ne sont pas utilisées à des fins publicitaires.
