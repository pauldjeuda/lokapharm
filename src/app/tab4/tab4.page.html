Politique de confidentialité

Dernière mise à jour : juillet 2026

1. Responsable du traitement

Lokaphar (cm.lokaphar.app) — contact : {{ supportEmail }}

2. Données collectées

  • Localisation : coordonnées GPS lorsque vous autorisez l'accès, pour afficher les pharmacies proches et calculer des itinéraires.
  • Favoris : liste des pharmacies enregistrées localement sur votre appareil.
  • Cache : données de pharmacies mises en cache localement pour améliorer les performances.

Nous ne collectons pas de compte utilisateur, d'identité, ni de données de paiement.

3. Finalités

Les données sont utilisées uniquement pour fournir les fonctionnalités de l'application : carte, recherche, itinéraires et favoris.

4. Partage avec des tiers

Lors de l'utilisation de la carte et des itinéraires, vos coordonnées peuvent être transmises aux services suivants :

  • OpenStreetMap / Overpass API (recherche de pharmacies)
  • Nominatim (géocodage inverse)
  • OSRM (calcul d'itinéraires)
  • Fournisseurs de tuiles cartographiques (OpenStreetMap, Carto, etc.)

Ces services sont soumis à leurs propres politiques de confidentialité.

5. Stockage et durée

Les favoris et le cache sont stockés sur votre appareil. Vous pouvez les supprimer en désinstallant l'application ou en effaçant les données de l'app.

6. Vos droits

Vous pouvez refuser l'accès à la localisation à tout moment dans les paramètres de votre appareil. Pour toute question : {{ supportEmail }}

7. Sécurité

Les communications réseau utilisent HTTPS. Aucun jeton d'authentification n'est stocké dans le navigateur ou l'application.
